# 权限与账号申请

生产事故里有一半来自权限过大。申请前先确认最小权限。

## 常规研发权限

GitHub 仓库只读/读写、预发环境、Figma 团队：由 **Team Lead** 在工单系统审批，SLA 为工作日 **4 小时** 内开通。

## 生产环境权限

生产数据库、生产 Kubernetes、客户数据导出：必须 **VP 级** 审批，且权限默认 7 天后过期，需再次申请。

禁止共享账号。禁止把生产密钥写入个人笔记或群聊。

## 账号开通清单

新人入职由 Buddy 代提工单，包含：

- 公司邮箱
- 飞书
- GitHub Organization
- 云厂商控制台（只读）
- Dify Console（产品/运营角色）

离职当天由 HR 触发「账号回收」工单，IT 在 2 小时内关闭全部权限。
